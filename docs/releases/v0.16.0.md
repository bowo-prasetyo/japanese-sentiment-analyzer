# Tenbin（天秤）v0.16.0 — 最初の公開リリース

日本語の**レビュー文**を「ポジティブ／ネガティブ／中立」に判定し、**どの語がどう効いたか**と、
**何が良く何が悪かったか（味・品質・サービス・価格などの観点別）**を示す、ブラウザだけで動くルールベースのエンジンです。
量れないときは推測せず、**「判定できません」**と答えます。

**▶ 試す: https://bowo-prasetyo.github.io/japanese-sentiment-analyzer/#/**

> このファイルは GitHub Release の本文として貼り付けるためのものです（リンクは `v0.16.0` タグを指します）。

## このリリースでできること

* **1件ずつ分析**: 判定・判定スコアのメーター・観点別の点数・感情の内訳・文中の語の強調表示・判定の根拠
* **まとめて分析**: 貼り付けや `.txt` / `.csv` で最大1000件を1件ずつ分析し、件数と割合・観点別の良し悪し・
  よく出た語・一覧を表示。CSV で書き出し
* **判定できません**: 辞書の語が見つからないときは中立と区別して表示し、その理由を示す
* **ユーザー辞書**: 自分の分野の語を画面から追加（今の文で試せる・語幹を提案・JSON で書き出し／読み込み）
* **プライバシー**: 入力した文はどこにも送信されません。サーバも APIキーも不要です
* **詳細設定**: 形態素解析（kuromoji.js、辞書 約18MB）を任意でオン
* **擬似API**: URL で分析結果の JSON を表示するページ

使い方は [ユーザーガイド](https://github.com/bowo-prasetyo/japanese-sentiment-analyzer/blob/v0.16.0/docs/user-guide.md) を見てください。

## どのくらい正確か

固定ブラインドベンチマーク b1（150件、各クラス50件）で、ブラウザの既定（文字列モード）で測りました。

| 指標 | 値 |
| --- | --- |
| ポジティブ・ネガティブの文を判定できた割合 | **87.0%** |
| 判定できた文での正解率 | **85.7%** |
| Macro-F1（「判定できません」は中立と予測したものとして計算） | 82.8% |

形態素解析をオンにすると、それぞれ 86.0% ／ 84.4% ／ 81.4% です。

**注意**: b1 は、辞書を見ていない別の AI エージェントが作成し、別のエージェントがラベルを確認したものです。
人が書いた文での検証はまだ行っていません。実際のレビューでの精度は、これと異なる可能性があります。
測り方は [評価](https://github.com/bowo-prasetyo/japanese-sentiment-analyzer/blob/v0.16.0/docs/evaluation.md) を見てください。

## できないこと

* 皮肉・文脈・長い文章の論理の理解（決まったルールで判定するため）
* 辞書にない表現の判定（ユーザー辞書で補えます）
* SNS のスラング・絵文字、レビュー以外の文章
* 人物の評価・採用・与信など、個人に影響する判断への利用（推奨しません）

## 互換性（0.x の間の方針）

バージョン 1.0 までは、次のものが予告なく変わることがあります。変わったときは [変更履歴](https://github.com/bowo-prasetyo/japanese-sentiment-analyzer/blob/v0.16.0/CHANGELOG.md) に書きます。

* 辞書 `data/config.json` の項目と形式
* 判定結果（同じ文でも、辞書やルールの改善で変わります）
* 擬似API のレスポンスの項目（項目の追加はありえます）

ユーザー辞書の書き出しファイル（`format: japanese-sentiment-analyzer/user-dictionary`、`version: 1`）は、
これまで名前を変えたときも読み込めるようにしてきました。今後も読み込めなくなる変更をする場合は、変更履歴に明記します。

## English summary

**Tenbin v0.16.0 is the first public release** of a browser-only, rule-based sentiment analyzer for Japanese reviews.
It classifies each review as positive, negative or neutral, shows which words drove the verdict, scores review aspects
(taste, quality, service, price, …), and answers "cannot judge" (判定できません) instead of guessing when it finds no known words.
New in this release: bulk analysis of up to 1,000 reviews from pasted text or `.txt` / `.csv` files, with a summary and CSV export.
Nothing you type leaves the browser.

On the fixed blind benchmark b1 (150 sentences, default string mode), it decides **87.0%** of positive/negative sentences and is
**85.7%** correct on those (macro-F1 82.8%). b1 was written and labelled by AI agents that never saw the dictionary; it has not yet
been validated on human-written text.

During 0.x, the dictionary format, verdicts and pseudo-API fields may change; changes are recorded in the changelog.

Full changelog: [CHANGELOG.md](https://github.com/bowo-prasetyo/japanese-sentiment-analyzer/blob/v0.16.0/CHANGELOG.md)
