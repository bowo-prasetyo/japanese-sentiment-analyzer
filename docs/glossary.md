# 用語集

Tenbin のドキュメントと画面で使う言葉です。1つの意味には1つの言葉を使います。
（ ）内は、コードや JSON での名前です。

## 判定と結果

| 用語 | 意味 |
| --- | --- |
| **判定** | ポジティブ／ネガティブ／中立／判定できません のどれか（`result`） |
| **判定できません** | 判定に使える語が1つもなかったこと。中立という判定ではない（`abstained: true`。`result` は `neutral` になる）。ベンチマークの記録では「ヒットなし」と書く |
| **中立** | 判定に使える語はあったが、判定スコアが −しきい値 と +しきい値 の間だったこと |
| **極性** | 語がポジティブかネガティブかを表す点数。プラスはほめ言葉、マイナスは不満（`polarity`）。例: 美味し = +1、不味 = −1 |
| **ヒット** | 判定に使った語。極性が 0 の語はヒットに数えない（`hits`） |
| **判定スコア** | ヒットの極性の合計 ÷ √ヒット数。判定に使う値（`normalizedScore`） |
| **合計スコア** | ヒットの極性の合計（`score`） |
| **しきい値** | 判定スコアがこの値以上ならポジティブ、−この値以下ならネガティブ。いまは 0.5（`threshold`） |
| **判定の根拠** | 判定に使った語と、その極性の計算（`matchedWords`） |
| **数えなかった語** | 辞書にあるが、条件・説明・用法・逆接の理由で判定に使わなかった語（`skippedWords`） |

## 辞書

| 用語 | 意味 |
| --- | --- |
| **組み込み辞書** | リポジトリの `data/config.json`。すべての人に共通 |
| **ユーザー辞書** | 閲覧者が画面から追加する語。そのブラウザにだけ保存される |
| **語幹** | 活用しても変わらない部分。辞書には語幹で登録する（「嬉しい」→「嬉し」） |
| **カテゴリ** | 語の分類。**観点**と**感情カテゴリ**の2種類がある |
| **観点** | レビューで何が良く何が悪かったかの分類。味・品質・サービス・価格・使いやすさ・配送・総合・結果・体の反応（`groups.レビュー観点`） |
| **感情カテゴリ** | 喜び・怒り・不安などの分類。画面では「感情・評価」と表示する |
| **否定** | 語の後ろにある「ない」「ず」などで、極性の符号を反転すること |
| **否定ウィンドウ** | 否定を探す範囲。語の後ろ8文字まで（`negationWindow`） |
| **強調** | 語の前にある「とても」「めっちゃ」などで、極性を何倍かにすること（`intensifiers`） |
| **逆接** | 「けど」「のに」「しかし」など、前後で内容が反対になる語。逆接があると後半だけで判定する（`splitters`） |
| **最長一致** | 長い語が見つかったら、その内側の短い語は数えないこと（「期待外れ」の中の「期待」） |

## モード

| 用語 | 意味 |
| --- | --- |
| **文字列モード** | 文を文字列のまま調べる方式。ブラウザの既定（形態素解析オフ） |
| **形態素解析** | 文を単語（形態素）に分けて調べる方式。kuromoji.js を使う。ブラウザではオプション、Node.js の評価では既定でオン |

## 評価

| 用語 | 意味 |
| --- | --- |
| **開発用セット** | 誤判定を見て辞書を調整してよいテスト用の文（`data/testset.json`） |
| **ホールドアウト** | 辞書の調整に使わず、作業の最後に一度だけ評価する文（`data/holdout.json`）。版ごとに入れ替わる |
| **ベンチマーク b1** | 辞書を見ていない作者が作った、固定のテスト用の文150件（`data/benchmark/b1.json`）。版の間の比較に使う |
| **Accuracy（正解率）** | すべての文のうち、判定が正解だった割合 |
| **Precision（適合率）** | あるクラス（例: ネガティブ）と判定した文のうち、本当にそのクラスだった割合 |
| **Recall（再現率）** | あるクラスの文のうち、正しくそのクラスと判定できた割合 |
| **F1** | Precision と Recall のバランスを1つにまとめた値（調和平均） |
| **Macro-F1** | ポジティブ・ネガティブ・中立の3クラスの F1 の平均。クラスの件数の偏りに左右されにくい。代表の指標 |
| **判定できた割合**（coverage） | 文のうち、「判定できません」にならなかった割合 |
| **ベースライン** | CI で守る Macro-F1 の下限（`data/eval-baseline.json`） |

## 技術

| 用語 | 意味 |
| --- | --- |
| **SRI** | Subresource Integrity。読み込むスクリプトのハッシュを HTML に書き、中身が変わっていたら実行しないしくみ |
| **CORS** | ブラウザが、ほかのサイトのデータを勝手に読めないようにするしくみ |
| **擬似API** | URL で文を渡すと、分析結果の JSON を表示する HTML ページ。本物の API ではない |
